# 本土病例感染源證據（figshare 欄位空白的 23 例）

資料：figshare 個案資料（Wu & Nordling 2024）的 `detail` 欄（疾管署新聞稿原文），由 `evidence_table.py` 逐字擷取。
Edge List 的 37 條有向邊（感染邊）都不涵蓋這 23 例，只涵蓋 `source_infected_case` 有填的病例，所以無法用來交叉核對。

判讀強度：

- **明確指名**（新聞稿寫出與特定個案的關係）：20、21、22、23、25、26、28、30、46、92、103、186、246、380；130、289 來自外部新聞。
- **屬於某群聚，但傳染者不確定**：
  - 35–38：新聞稿只說屬「案 34 相關群聚」，沒有指名是案 34 本人傳的。
  - 168、169：「案 160、168 及案 169 為案 124 之接觸者」。案 160 是 3/10 自美返國的境外移入、3/14 頭痛就醫，比案 124 的 3/17 發病早，所以傳染者可能是案 160 而不是案 124；案 124 本身也可能是被案 160 傳染。
  - 29：是案 27 的小兒子，但他 1/29–30 就有症狀，比案 27（2/6）早，且常往返武漢；傳染方向可能是 29 → 27。
- 不論哪一種，這 23 例都屬於已有指標個案的群聚，**不是獨立的輸入源**，所以不放進種子；有疑義的只影響「群聚的指標個案是誰、何時感染」。
