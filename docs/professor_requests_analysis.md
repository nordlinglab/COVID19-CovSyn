## 9. 1.7 定案（2026-10-19 使用者裁決）

- 感染日用**一次定死的推估值**，不在每次模擬重抽：有症狀者 = 發病日 − 模型潛伏期分布的中位數；無症狀者 = 確診日 − 臺灣「感染到確診」中位數；有推定感染日者直接用。
- 推估值超出限制（出國日、接觸期間、不晚於發病日與確診日）時，**截到最近的界限**，不重抽。
- 種子名單（每人的感染日、年齡、性別、縣市）存成 CSV 隨程式一起版本控制，所有模擬用同一份。
- 敏感度分析：截斷點前後各移 3 天，重新產生種子名單，只重跑 Monte Carlo（不重新校準）。

## 11. 職場每日同事接觸目標改為 4.84（2026-10-19 使用者裁決）

**算法**（重現：`covid19-research/scripts/summarize_taiwan_contact_data.py` 的 `at_work()`；資料 Fu 2010，Zenodo 10.5281/zenodo.6385759，每位受訪者填一天日誌）：

1. 受僱者：職業代碼 3 辦公室／專業、4 店員／商人、5 勞力、6 農漁業（905 人）。
2. 日誌在平日（週一到週五）：616 人。
3. 工作接觸：地點勾「工作」且沒有勾「家」（家族事業的接觸屬家戶層）。
4. **當天有上班**：至少一筆工作接觸，不限時長。日誌沒有「當天是否上班」欄位，這是間接判斷；616 人中 200 人一筆都沒有（請假、輪休、地點勾成「其他」、漏填，或真的獨自工作），排除後 **416 人**。
5. 同事的近似：工作接觸 ≥15 分鐘（時長代碼 3–5）且「每天或幾乎每天見面」（頻率代碼 1），排除客人等偶爾的接觸。

**結果**（416 人，每人每日）：平均 **4.84** [4.25, 5.49]，中位數 3，P75 7，P90 12，0 人 28.1%。
對照：不限頻率（含客人）5.88 [5.21, 6.57]、中位數 4；全部 616 人（含沒上班的日子）3.97。

**判斷的限制**（論文要寫）：

- 「至少一筆工作接觸 = 當天有上班」是假設；真的整天沒碰到人的獨自工作者也會被排除，把同事接觸地點勾成「其他」的上班者也會被排除。
- 「每天見面」是同事的近似；每天光顧的熟客會被算入，不常見面的同事會被排除。
- 2010 年疫情前資料；日誌每人上限 40 筆（616 人中 28 人填滿）。

**為什麼不用 3.97**：模型假設受僱者平日都上班，3.97 把沒上班的日子也平均進去，會讓每位受僱者每天碰到的同事偏少。獨自工作者在模型中已由普查公司規模表示（21.6% 的就業者在不到 5 人的場所），所以目標應排除沒上班的日子，但保留獨自工作者。

## 14. spread_Taiwan 改用新的多重種子（2026-10-19 使用者裁決）

- 以後 `spread_Taiwan`（現行 `spread_Taiwan_weight`）也要用新的 infection queue（境外移入 + 本土不明），不再只放 1 個 source case。
- 查證的影響：
  - **校準不受影響**：firefly 的兩個成本函數呼叫 `run_covid(seed, P, ...)`，預設 `mode='result'`（1 個 index case、time_limit = 1，只模擬它本身的接觸與傳染），不用 spread 情境。
  - **驗收要改**：`verify_phase_d.py` 有約 30 處用 `r['course'][0]`（每次模擬的第一位病人）當 index case，例如 R、offspring k、各層每例感染數（對 Cheng 2020）、Jian 窗口接觸數。多重種子後，「第一位病人」只是其中一個種子，這些指標要重新定義要算在哪些病人身上；Jian 比較改在全部確診病例上（見第 13 節）。
  - **R0 benchmark**：`spread_Taiwan_weight` 也是 R0 研究產生合成資料的情境（`--contact_weight`，referee item B2）；改成多重種子會改變那邊的資料。需決定是否保留單一種子的版本給 R0。
- 查證補充（2026-10-19）：
  - firefly 兩個成本函數（`firefly_optimizer._run_simulation_batch`、`fast_cost` 第 173 行）都以預設 `mode='result'` 呼叫 `run_covid`：1 個 source case、`time_limit = 1`。佇列只處理感染日 ≤ 1 的病例，所以除了 index case，只有在第 0–1 天就被傳染的人（latent period 可為 0，`data_synthesize.py:752`，少見）也會跑完並計入 Cheng 分組；R、k 等純量只取 index case。firefly 本身不受 spread 情境影響。
  - 但每一輪的 B60 候選挑選（`select_by_checklist.py`，`MODES = spread_Taiwan_weight, taiwan_first_outbreak`）用這兩個情境跑驗收清單來選最終候選，所以**挑選結果會受新種子影響**。
- R0 benchmark：使用者選 (b)。新增多重種子的情境給 CovSyn 驗證；`spread_Taiwan_weight` 保留單一種子，其他人仍用它產生模擬資料做分析。
- 校準的 index case 與 Cheng 2020 的組成（2026-10-19 發現，待決定）：firefly 每次模擬 1 個 index case，都是在臺灣社區被感染的人。Cheng 2020（`lit/markdown/cheng2020_TracingSymptomJAMAInternMed.md` 表 2）的 100 個 index case 包含本土（967 名接觸者，attack rate 1.6%）與境外移入（1,794 名接觸者，0.2%）。校準目標混了兩種 index case，模型只有一種；這個問題在多重種子之前就存在，實作境外移入規則（入境前不產生接觸、檢疫）後，才有可能讓校準的 index case 依 Cheng 的組成混合。
- 裁決（2026-10-19）：Cheng 2020 index case 組成的問題**不處理，列為論文限制**（拿不到依來源拆開的分層資料，且使用者要求簡化）。限制內容：Cheng 2020 的 100 個 index case 含境外移入（1,794 名接觸者，clinical attack rate 0.2%），其「其他」類含航空機組員與乘客，而校準把「其他」類當社區層目標；模型的 index case 都是本土、沒有機上接觸，所以社區層傳染機率可能被校準得偏低。本土 index case 的 clinical attack rate 1.6%（含無症狀 18/967 = 1.9%），境外移入 0.2%。
- **更正（2026-10-19，同日）**：上一條限制的機制寫錯。E56 起 Cheng 2020 的三層（家戶、醫療、社區）是以「**每個 index case 傳染幾人**」校準（家戶 10、醫療 6、社區 1 人 / 100 個 index case；`firefly_optimizer.py` 第 725 行，權重 1），不是每名接觸者的傳染率，所以機上接觸者只影響分母、不是主要問題。真正的問題是 **index case 的組成**：Cheng 的前 100 例中，境外移入 71 例、本土 29 例（依 figshare 個案 1–100 號）。本土 index case 傳染 18 人（每例 0.62，Poisson 95% 區間 0.37–0.98），境外移入傳染 4 人（每例 0.056）；混合後每例 0.22（0.14–0.33）。模型的 index case 都是本土、在社區生活，卻被校準到混合後的每例傳染數，**可能低估約 2.8 倍**（0.62 ÷ 0.22）。這與 run 17 的 R = 0.356 偏低、教授說「模擬疫情太小」可能有關。待使用者決定補救方式。

## 15. 本土校準、境外移入驗證（2026-10-19 使用者裁決）

**結論**

1. **本土 index case 用來校準**：Cheng 2020 的家戶、醫療、社區「每個 index case 傳染幾人」目標，改為只代表本土病人。本土 29 例（推估，figshare 1–100 號）傳染 18 人，每例 0.62（Poisson 95% 0.37–0.98）；混合 100 例為 0.22。校準目標的做法待定：(a) 三層各乘 0.62 ÷ 0.22 ≈ 2.8（家戶 0.28、醫療 0.17、社區 0.03，假設本土各層比例與整體相同），或 (b) 只校準總數 0.62。建議 (a)。
2. **境外移入 index case 只驗證、不校準**：所有人共用同一套參數；境外移入的差別只在規則，規則全部由資料與法規直接決定，不加可調參數：
   - 入境日：figshare 資料；
   - 入境前不產生接觸（1.9）；
   - 是否居家檢疫：資料的發現方式＋政策日期（2/7 中港澳、3/19 全面）；
   - 檢疫中只接觸家人（決定 2 選 (a) 時）。
3. **驗證指標（新增到驗收清單）**：新的多重種子情境中，每位境外移入種子在臺灣平均傳染幾人，對照 Cheng 2020 的 0.056（4 ÷ 71，Poisson 95% 0.015–0.14）；並以我們分類表的「境外移入傳染本土」人數算出第二個參考值互相對照。
4. **若驗證差很多**：才考慮加入資料無法決定的參數（例如檢疫違規率、機場攔截時間）並用 0.056 校準；此時境外移入失去獨立驗證，論文要說明。0.056 只來自 4 個傳染事件，用來校準有過度配適的風險。

**限制**：29 / 71 為推估（Cheng 未公布）；Cheng 只給總數、沒有依來源分層；樣本小（本土 18、境外移入 4）。
